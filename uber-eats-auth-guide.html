🔐 Obtener Access Token de Uber Eats

⚠️ Importante: Asegúrate de haber configurado las URLs en tu Developer Dashboard antes de continuar.

📋 Paso 1: Configurar URLs en Developer Dashboard

En tu Developer Dashboard, agrega:

Redirect URIs:

https://posfagotto.cl/auth/uber/callback

Origin URIs:

https://posfagotto.cl

Webhook URL:

https://posfagotto.cl/api/uber-eats/webhook

🔑 Paso 2: Autorizar la aplicación

Haz clic en el siguiente enlace para autorizar tu aplicación:

🚀 Autorizar Aplicación

URL completa:

https://login.uber.com/oauth/v2/authorize?response_type=code&client_id=EsXBQrBR3Z990kg7MFXINVgURoUMlsiv&scope=eats.store%20eats.orders&redirect_uri=https://posfagotto.cl/auth/uber/callback&state=random_state_123

💻 Paso 3: Crear endpoint de callback

Necesitas crear este endpoint en tu servidor Laravel para capturar el código de autorización:

Route::get('/auth/uber/callback', function(Request $request) { $code = $request->get('code'); // Intercambiar el código por un access token $response = Http::post('https://login.uber.com/oauth/v2/token', [ 'client_id' => env('UBER_EATS_CLIENT_ID'), 'client_secret' => env('UBER_EATS_CLIENT_SECRET'), 'grant_type' => 'authorization_code', 'code' => $code, 'redirect_uri' => 'https://posfagotto.cl/auth/uber/callback' ]); $data = $response->json(); return [ 'access_token' => $data['access_token'], 'refresh_token' => $data['refresh_token'], 'expires_in' => $data['expires_in'] ]; });

🎯 Paso 4: Guardar el Access Token

Una vez que obtengas el access_token, actualiza tu archivo .env:

UBER_EATS_ACCESS_TOKEN=tu_access_token_aqui

🏪 Paso 5: Obtener Store ID

Para obtener tu Store ID, usa el access token en esta llamada a la API:

GET https://api.uber.com/v1/eats/stores Authorization: Bearer tu_access_token_aqui

🔔 Paso 6: Configurar Webhooks

En tu Developer Dashboard, configura el webhook para recibir notificaciones en tiempo real:

https://posfagotto.cl/api/uber-eats/webhook

Eventos a suscribir:

  • eats.order.placed
  • eats.order.status_changed
  • eats.order.cancelled
🎉 ¡Listo! Una vez completados todos los pasos, tu integración de Uber Eats estará funcionando al 100%.
