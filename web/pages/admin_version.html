Actualizar Versión Oficial

¿Cuándo actualizar?
Actualiza la versión oficial cuando publiques una nueva versión en GitHub y quieras que todos los negocios se consideren "desactualizados" hasta que actualicen.
Formato: X.Y.Z (ejemplo: 1.11.51)
Para registrar quién hizo el cambio

¿Cómo Funciona?

🔍 Sistema de Triple Verificación
  1. 1️⃣ Base de Datos (Prioritaria)
    La versión que TÚ configuras aquí. Es la más confiable porque la controlas manualmente.
  2. 2️⃣ GitHub API
    Si la DB no está disponible, consulta el último release de GitHub automáticamente.
  3. 3️⃣ Fallback Hardcoded
    Si todo falla, usa la versión hardcodeada en el código (1.11.50).
Recomendación: Siempre actualiza la versión aquí cuando publiques un nuevo release en GitHub. Así tienes control total.
